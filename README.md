# 🤖 AI Interview Generator

A Python-based AI Interview Question Generator that helps users practice interview questions in a simple and interactive way.

---

## 🚀 Features
- Generates interview questions dynamically
- Simple command-line interface (CLI)
- Beginner-friendly Python project
- Easy to extend with AI APIs in future
- Can be improved with scoring and timer features

---

## 🛠️ Technologies Used
- Python 🐍
- Basic Programming Logic
- File Handling (optional)
- dotenv (optional for future API usage)
